# Verti

Landing page residencial em React, TypeScript, Tailwind CSS e WebGL.

Use Node.js 22.12 ou superior. Na raiz, execute `npm ci` e depois `npm run dev`. Abra http://127.0.0.1:5173/. Para compilar, execute `npm run build`.

Os arquivos WebP em public/images acompanham o projeto. O formulário demonstrativo guarda os dados no navegador.
